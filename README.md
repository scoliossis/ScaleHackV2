## Setup
1. Clone the repo
   ```sh
   git clone https://github.com/scoliossis/worse-base
   ```
2. Open `build.gradle.kts` in IntelliJ IDEA

   ![buildgradlektsfile.png](repo%2Fbuildgradlektsfile.png)

3. Open IntelliJ Settings

   ![intellijsettings.png](repo%2Fintellijsettings.png)

   Go to `Build, Execution, Deployment` > `Gradle` and set the Gradle JVM to any version of the Java 17 JDK

   ![gradlejvm17.png](repo%2Fgradlejvm17.png)

   Apply and press OK
4. Open Project Structure

   ![intellijprojectstructure.png](repo%2Fintellijprojectstructure.png)

   Set the SDK to any version of the Java 1.8 JDK

   ![projectjdk.png](repo%2Fprojectjdk.png)
